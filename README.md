# 🧩 Tayoru — Modular Python Desktop Application

**Tayoru** is a modular Python desktop application built to explore 🔐 secure authentication, 💾 local data management, 🤖 AI-assisted workflows, and ⚙️ software automation.

The project is developed using **Python, PySide6, SQLite, and bcrypt**, with a modular structure separating authentication, dashboard functionality, terminal interaction, testing, and AI-agent experimentation.

## 🚀 Key Features

* 🔐 **Secure Authentication** — User authentication using **bcrypt password hashing** with SQLite-backed user management.
* 🖥️ **Desktop GUI** — PySide6-based graphical interface with structured authentication and application workflows.
* 🗄️ **Local Database** — SQLite integration for persistent user data management.
* 🧩 **Modular Architecture** — Separate components for authentication, dashboard functionality, terminal interaction, testing, and AI-agent experimentation.
* 🤖 **AI & Automation** — Dedicated AI-agent components exploring how software can interact with application functionality.
* 🧪 **Testing** — Separate test modules for validating application components and functionality.
* 🐍 **Python Development** — Practical implementation of functions, modules, database operations, exception handling, and application logic.
* 🐧 **Linux Development** — Developed and tested within a Linux/Python virtual-environment workflow.
